# 📘 Python Base Guia

Repositório de estudos com exemplos práticos de Python, organizado por módulos para evolução progressiva do básico ao avançado.

---

## 📂 Estrutura do Projeto

* 01 - Condicionais
* 02 - Laços
* 03 - Listas
* 04 - Tuplas
* 05 - Conjuntos (Set)
* 06 - Dicionários
* 07 - Strings
* 08 - Funções
* 09 - SQLite

Cada módulo contém exemplos em três níveis:

* 🟢 Básico
* 🟡 Intermediário
* 🔴 Avançado

---

## 🎯 Objetivo

Consolidar a base em Python com foco em:

* Lógica de programação
* Estruturas de dados
* Boas práticas
* Preparação para backend e automações

---

## 🚀 Como utilizar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/python-base-guia.git
```

2. Acesse a pasta desejada:

```bash
cd 01-condicionais
```

3. Execute os exemplos:

```bash
python exemplos.py
```
